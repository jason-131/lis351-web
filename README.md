# Campus Compass

Campus Compass is a one-page student resource guide created for LIS 351 Assignment 4. It provides campus resource starting points and practical tips for students.

## Features

- Navigation links to each section
- Hero banner with a campus image
- Three feature blocks
- Campus resource overview
- Two practical tip cards
- Contact section and image credits
- Responsive layout for desktop and smaller screens

## Files

- `index.html` — Website content and structure
- `styles.css` — Styling, including completed TODO blocks A–O
- `images/` — Campus photo, illustration, and icons

## View the Website

Open `index.html` in a browser, or visit the published GitHub Pages site.
